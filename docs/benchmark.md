# Замер времени iolistgen

<!-- Отчёт записан скриптом examples/benchmark.py: перезапустите его, а не правьте вручную. -->

Проверка и генерация по перечню сигналов: медиана 30 повторов после прогрева; команда целиком — медиана 5 запусков отдельного процесса. Дата замера: 2026-10-16.

## Машина

| | |
|---|---|
| Процессор | AMD Ryzen 7 7800X3D 8-Core Processor, логических ядер: 16 |
| ОС | Windows-11-10.0.26300-SP0 |
| Python | CPython 3.12.10 |
| iolistgen | 0.1.0 |
| Зависимости | pydantic 2.14.1, openpyxl 3.1.5, Jinja2 3.1.6 |

Генераторы в замере: `st-codesys`, `modbus-map`, `scada-csv`, `alarm-list`, `docs-table`.

Процесс целиком включает старт интерпретатора Python и импорт пакета (pydantic, openpyxl, Jinja2) — это большая часть времени команды на перечне такого размера.
Старт команды без работы (`iolistgen --version`): медиана 856,6 мс (мин. 853,6, макс. 867,0).

## Как повторить

```bash
python examples/synthetic/make_synthetic.py      # перечень на 300 сигналов (зерно 2026)
python examples/benchmark.py --repeat 30 --cli-repeat 5
```

Оценку ручного заведения тех же сигналов автор приводит в README (раздел «Замер времени»).
